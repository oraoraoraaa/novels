# Novels

使用 LaTeX 管理的小说写作仓库。

## 作品

- [《主人、笨狗与綾》第一册](book-01/README.md)：工程已经初始化，正文尚未开始扩写。

## 仓库约定

- 每一册使用独立目录，避免正文、设定与构建产物互相混杂。
- 正文按章拆分为多个 LaTeX 文件，由每册的 `main.tex` 统一装配。
- 剧情大纲和连续性资料保留为 Markdown，不直接混入正文源文件。
- 提交信息遵循 [Conventional Commits](https://www.conventionalcommits.org/)；具体协作规则见 [AGENTS.md](AGENTS.md)。
